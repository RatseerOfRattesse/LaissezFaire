# LaissezFaire
Saving the builder playstyle with the Free Market.

Laissez Faire aims to make villagers once more useful with overhauled trades and employment mechanics.

# Installation
This mod is built for Fabric 26.2. Install like any other MC mod, and also install Fabric API.

(any Terra reviewers new to mods using vanilla launcher, install fabric from their [site](fabricmc.net), then make a folder called mods in your installation root and drop in the file from the releases page here) (if you don't have MC and are stuck having to review this feel free to just make something up off of my devlogs. If you must, you can try downloading this source code and building the project in IntelliJ)
